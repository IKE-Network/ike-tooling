# About IKE Knowledge SPI

Zero-dependency contract module for the IKE knowledge pipeline: ServiceLoader service interfaces (assemble, export, bindings, verify), the ViewSpec dimension vocabulary, and the properties codec that crosses the forked-JVM execution seam.
