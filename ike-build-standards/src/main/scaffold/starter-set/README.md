# @setName@ Starter Knowledge

The @tag@ knowledge set: an append-only version ledger whose releases are change
sets. Generated by `ike:starter-set-create`.

**Set identity (permanent):** `@setUuid@` — the type-5 namespace from which every
identity in the set derives. Never change it; never reuse a birth FQN.

The standard operating procedure is the `dev-knowledge-set-sop` topic family in
`ike-lab-documents`. The short loop:

```bash
mvn install                       # ledger -> bindings, change set, glossary, KB
open ~/Solor/@slug@-kb            # select in Komet; verify; edits are captured
```

Captured verification change sets land in `~/Solor/@slug@-kb/changeSets/` and feed
the next iteration as `CHANGESET` inputs in `@slug@-kb/pom.xml`.
